Relative Performance

VistaCharts.

Total-return history for any listed security against a benchmark, from 3 months to max available history. Series are dividend- and split-adjusted, rebased to zero at the start of the window, and intersected on common trading days so the comparison is honest. Trailing and calendar-year tables are measured over full common history, whatever window the chart shows.

Return & risk — selected window

Volatility and tracking error are annualised from daily returns (√252). Annualised return is shown only for windows longer than about 13 months — annualising a shorter window converts noise into a headline. Sharpe, Sortino and alpha assume a 0% risk-free rate; capture ratios are computed on monthly returns.
